# P2P Exchange — внутренняя платформа по продаже USDT

Внутренний P2P-обменник для сотрудников (по образу P2P-разделов Bybit / Binance),
где **вы — администратор и посредник**. Сотрудники (трейдеры) вносят депозит на
обменник, торгуют USDT по объявлениям с эскроу, а вы открываете реальные сделки на
внешней бирже (Bybit) и льёте выплаты на их реквизиты.

> ⚠️ Платформа предназначена для внутреннего использования доверенной командой.
> Перед реальной эксплуатацией смените все секреты в `.env`, включите 2FA у админа,
> настройте резервное копирование БД и ограничьте сетевой доступ.

## Как это работает (бизнес-модель)

1. **Админ** создаёт аккаунты сотрудников, задаёт им комиссию, спред и лимиты.
2. **Сотрудник** отправляет заявку на депозит → админ подтверждает → баланс зачисляется.
3. Сотрудники публикуют **объявления** (купля/продажа USDT) с фикс. или плавающей ценой.
4. Другой участник **берёт объявление** → создаётся **сделка**: крипта продавца
   блокируется в **эскроу**, запускается таймер оплаты.
5. Покупатель оплачивает фиат на реквизиты и жмёт «Я оплатил», продавец подтверждает —
   эскроу отпускается покупателю (за вычетом комиссии платформы), сделка завершается.
6. Спорные ситуации решает админ (арбитраж: вернуть продавцу / отпустить покупателю).
7. **Хеджирование**: под сделки/оборот админ создаёт **реальные ордера на Bybit**
   (через адаптер) и указывает реквизиты выплат — вы закрываете позицию на внешней бирже.

Учёт средств ведётся **двойной записью** (double-entry ledger): каждое движение денег
сбалансировано, а системный аккаунт `house` выступает контрагентом для депозитов/выводов.

## Технологии

| Слой        | Технологии |
|-------------|-----------|
| Бэкенд      | NestJS 10, TypeScript, Prisma 5, PostgreSQL, Redis, Socket.IO, Passport JWT, argon2, decimal.js |

## Структура

```
p2p-exchange/
├── backend/                 # NestJS API + WebSocket + Prisma
│   ├── prisma/
│   │   ├── schema.prisma    # доменная модель
│   │   └── seed.ts          # админ, system-аккаунт, демо-трейдеры
│   └── src/
│       ├── common/          # деньги (Decimal), guards, decorators, filters
│       ├── modules/
│       │   ├── auth/            # JWT, refresh-ротация, 2FA (TOTP)
│       │   ├── users/           # управление сотрудниками, комиссии, лимиты
│       │   ├── wallets/         # кошельки + двойная запись (ledger)
│       │   ├── payment-methods/ # реквизиты
│       │   ├── advertisements/  # P2P order book
│       │   ├── deals/           # эскроу, автомат статусов, чат, споры, таймеры
│       │   ├── treasury/        # депозиты/выводы + ручные корректировки
│       │   ├── rates/           # рыночный курс + спред + ручной курс
│       │   ├── exchange/        # адаптер биржи (Bybit / Mock) + хедж-ордера
│       │   ├── realtime/        # WebSocket-шлюз
│       │   ├── notifications/   # уведомления
│       │   └── admin/           # дашборд, аналитика, аудит
│       ├── app.module.ts
│       └── main.ts
├── frontend/                # Next.js UI (кабинет трейдера + админ-панель)
└── docker-compose.yml       # PostgreSQL + Redis
```

## Быстрый старт

### 1. Инфраструктура (Postgres + Redis)

```bash
docker compose up -d
```

### 2. Бэкенд

```bash
cd backend
cp .env.example .env          # при необходимости отредактируйте секреты
npm install
npm run prisma:generate
npm run prisma:migrate         # создаст таблицы (dev-миграция)
npm run db:seed                # админ + system-аккаунт + демо-трейдеры
npm run start:dev              # http://localhost:4000/api  (Swagger: /api/docs)
```

### 3. Фронтенд

```bash
cd frontend
cp .env.local.example .env.local
npm install
npm run dev                    # http://localhost:3000
```

## Подключение реального Bybit

По умолчанию используется `mock`-адаптер (мгновенное исполнение, статичный курс).
Чтобы включить реальную биржу, в `backend/.env`:

```env
EXCHANGE_ADAPTER=bybit
BYBIT_API_KEY=...
BYBIT_API_SECRET=...
BYBIT_TESTNET=true      # начните с testnet
```

Адаптер (`backend/src/modules/exchange/adapters/bybit.adapter.ts`) реализует
подпись запросов Bybit v5 и методы: тикер, создание/статус/отмена ордера.

## Ключевые особенности

- **Двойная запись**: невозможно «создать» деньги — каждая транзакция сбалансирована,
  отрицательный баланс на пользовательских кошельках запрещён.
- **Эскроу**: крипта продавца замораживается на время сделки; авто-возврат по таймауту.
- **Роли и доступ**: глобальные guard'ы (JWT + Roles), маршруты `admin/*` доступны только админу.
- **Реалтайм**: обновления балансов, статусов сделок, чат и уведомления через WebSocket.
- **Безопасность**: argon2-хеши паролей, ротация refresh-токенов, 2FA (TOTP), helmet, throttling.
- **Комиссии/спред**: настраиваются глобально и переопределяются для каждого сотрудника.

## Экономика (по умолчанию, настраивается в `.env`)

- `DEFAULT_TAKER_FEE=0.005` — комиссия платформы (0.5%), удерживается из отпускаемой крипты.
- `DEFAULT_SPREAD=0.01` — спред к рыночной цене для котировок.
- `DEAL_PAYMENT_WINDOW_MIN=15` — окно оплаты сделки до авто-истечения.
